# 云野小镇 · 可部署的本地完整版

独立于 NETPUNKS 主项目的 Town Star 风格农场小游戏。现在同时支持本地体验和 Sepolia 链上测试，包括真实部署的 TOM ERC-20、建筑 ERC-721、玩家市场和经过服务端验证的阶段奖励。网页新版按要求仅在本地运行，尚未发布到服务器。原有本地体验存档保留；教学 TODO 包和教师包没有修改。

本地网址：http://127.0.0.1:4389/

连接步骤、合约地址、存档范围和部署说明见 [SEPOLIA.md](SEPOLIA.md)。下文经营规则同时适用于本地与链上模式；A/B 账户及示例挂单仅属于本地体验模式，连接钱包后使用独立的链上账户。

## 启动与验证

在本目录运行 `python3 -m http.server 4389 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4389/ 。运行 `node --test test/*.test.mjs` 验证规则。

新版存档使用 `meadow-farm-world-v6`，首次从 `meadow-farm-world-v5`／`meadow-farm-world-v4`／`meadow-farm-world-v3`／`net-meadow-world-v2`／`net-meadow-v1` 迁移并保留旧记录。独立新版键防止尚未刷新的旧页面覆盖新规则下的存档。不同域名、端口拥有独立存档，浏览器测试使用独立端口，保留用户的原农场。不要重置现有用户农场来演示新规则。

## 普通设施、NFT 与货币

- 经营币：建设普通设施的游戏资金。18 类、46 款普通建造项包括麦田、道路、果树、综合仓库，以及水井、磨坊、面包房、太阳能、风力机、水塔、筒仓、货仓、搬运车、快递站、牧场、蛋糕房。每次成功放置按标价扣款；取消建造、无效位置或余额不足不扣款。
- 普通设施：木色、灰色外观，仅属于本轮。普通设施的生产配方真实生效，仓储、灌溉和运输效果参与经营规则。新开局后需要重新购买。
- 点击已放置的普通设施或道路，可预览拆除，按实付经营币的 50% 返还（向下取整），确认后到账；不改变 TOM 与 NFT。取消不拆除、不退款，同一设施只能退款一次。旧版普通设施缺少实付记录时按对应型号计价，旧地图赠送道路及无购置记录的免费配套返还 0。货车行驶中的路线需等回站后再拆除。拆除生产设施会取消其未入库批次、已耗原料不退；拆除仓库保留库存并减少容量。开局住宅与货运站保留，NFT 使用收回背包。
- NFT：14 类、22 种市场型号，用 TOM 购买和交易。同类型 NFT 比普通设施更快，或拥有更大容量、范围和运输能力。地图使用青绿外观、专属底座和金色星标；仓库状态图标使用实线双边框，普通设施使用虚线边框。
- 已拥有的 NFT 放置不扣经营币或 TOM；同一 NFT ID 同时只能放置一次，持有几件就最多放几件。收回后可再次放置或挂单。挂单期间不能使用。NFT 背包显示可放置数／持有数。
- TOM Token：永久保留的支付、交易和挑战奖励代币，独立于经营币。内部余额沿用 `token` 字段。新资产 ID 使用 `NFT-`；旧 `NET-` 身份与关联保持不变，只将显示标签改为 `NFT-`。

`dist/ordinary.mjs` 定义普通型号，`dist/rules.mjs` 的 `BASIC_BUILDINGS` 定义经营币价格，`CATALOG` 定义 NFT 的 TOM 发行价和能力。14 类生产与工具设施各提供基础、改良、高效三档；价格逐档提高，产量、容量或运输效率实际提升。普通容量为对应 NFT 的 60%／75%／90%，普通快递为 10／9／8 秒；同档 NFT 保持更强能力。麦田、道路、果树、综合仓库为通用配套。

## 新开局与奖励

- 每次想获得下一笔新的 TOM 奖励，都必须使用未领取过奖励的新一轮农场。领取过奖励的农场即使到了下一天，也必须先新开局建设。
- 空地开局发放 3000 经营币；也可沿用上一轮布局，按现行经营币标价一键重建，只保留货运站与住宅。普通设施可按原位置、原型号重新购买，已持有且未挂单的 NFT 可原位免费放置。农产品、清水、电力、订单进度、星星和在制批次重置，生产总量归零。
- 永久保留 TOM、NFT 的准确 ID 与持有量、挂单、收藏、交易历史、已结算过的一次性产业委托和日挑战次数。NFT 回到背包，清空本轮未完成批次及临时电量，开局可免费放置。
- 先购买普通设施或放置 NFT 并接通产线，再主动开始限时挑战。必须有麦田、有效粮仓与加工仓、计划要求的生产设施。普通和 NFT 均可满足所需类型；NFT 仓储也可替代普通仓储参与生产、发货。
- 未完成任务可以反复重新挑战，包括进行中主动重试、超时后重试；重试保留建筑、道路、NFT、经营币、库存和已支付的生产批次，重新计算本次倒计时及目标进度。旧批次和旧发车不计入新任务，正在运送的货物仍正常入库／结算。
- 每天五个阶段依次解锁，每阶段限领一次，北京时间 00:00 重置当日阶段进度；TOM 不清零。未完成可保留建设无限重试，不丢失已领阶段奖励；已达标未领奖时奖励锁定至当日结束。领取后需开启新一轮才可挑战下一阶段，可付经营币复用布局，新开局不能重置当日已领奖阶段。暂停、关页、换账户不延长真实倒计时。
- 每轮只结算一个阶段的 TOM：当次限时任务奖励和已达成、尚未结算的一次性产业委托奖励同时发放。产业委托不提供第二个独立领奖入口。新开局、跨日或刷新不能让上一轮的产出和发货计入新一轮。
- 旧农场保持原资产、资金和库存，标为“旧农场”；仍可经营，但领取新 TOM 前须主动新开局，迁移时不自动拆除或清空用户农场。

## 生产、仓储与布局

水井产水，麦田耗水产麦，磨坊加工面粉，面包房烘焙；牧场用小麦和清水产奶，蛋糕房耗用面粉、牛奶、面包与电力。所有配方实际扣除原料，仓满会暂停入库。

设施需紧邻通往货运站的道路。高物体遮阴、建筑挡风、灌溉范围与搬运距离影响实际周期。普通和 NFT 设施共用相同规则。运输提速取最强效果，容量扩展可以叠加。

空地开局的粮仓和加工仓从零开始，接通综合仓库后各增加 200；筒仓和货仓提供额外容量。加工品共用加工仓，清水与电力各有初始 100 容量。太阳能前 120 秒白天发电、后 60 秒夜晚暂停；风力机持续发电。暂无工资、燃油、完整工人调度与离线生产。

仓库图标实时显示占用比例、将满、满仓、超容、断路或暂停状态。点击图标或仓库打开货物详情，显示共享库存、剩余容量、本仓扩容贡献与实际运来的批次。在途货物卸货后才计入库存，收回仓储保留现有库存。

村民在实际批次最后的搬运阶段抱货送往仓库，优先沿道路，避开建筑和溪流。虚线、货物图标及右侧“货物流动”显示运输过程；到达时才入库。暂停冻结动画与进度，满仓时等待卸货，旧存档或重新放置后重建路线。

## 市场

市场包含发行、玩家挂单、我的 NFT、收藏和交易动态，支持类型、品质、价格、名称和编号搜索。两个本地体验账户 A／B 的农场与余额独立，B 初始示例挂单明确用于试玩。买卖等额转移 TOM 与同一件 NFT，不连接 NETPUNKS Render 网站的真实账户、合约或余额。

规则借鉴 Town Star 的布局、生产和贸易思路，名称、价格和奖励为本原型自定。参考：[标准规则书（2022）](https://news.gala.com/common-ground-world/the-town-star-rulebook/)、[邻近影响](https://support.gala.com/hc/en-us/articles/22440841171355-Proximity-Effects-In-Town-Star)。


## 任务入口与准备检查

查看任务始终可点击，不开始倒计时。旧农场、已领奖或设施未准备好时也可查看具体原因；未完成任务可在这里重新开始，保留建设与库存。任务窗口逐项区分未建造、已暂停、未接通道路，并提供新开局说明和普通设施商店入口；准备齐全且本轮未领奖、当前阶段尚未领奖时，可以开始或重试任务。确认时再次验证状态，状态改变时刷新说明，不再无提示地忽略点击。


## 商店发现与任务对应

经营币商店展示 18 类、46 款设施，可按农业生产、供水能源、仓储物流、道路装饰，以及档位和名称筛选。任务使用的类型标签与商店家族名称对应，缺项有直接购买入口。粮食仓储可购买综合仓库或筒仓，加工仓储可购买综合仓库或货仓；任一档位均可满足任务类型条件。资金不足仍展示商品、价格和差额，不隐藏商品。选择商品后按该型号价格在成功放置时扣款，保存型号 ID 与实付价，刷新不降档或变为 NFT。


## 简体中文与 English

右上角及弹窗内的双语按钮可立即切换简体中文／English，默认简体中文。选择单独保存在 `meadow-farm-language`，刷新后沿用；语言切换更新界面文字，不重开农场、不改变资产或任务进度，保留已输入的搜索词和价格。

`dist/translations.mjs` 提供英文词库，`dist/i18n.mjs` 处理带数量的任务、退款、运输和生产提示，`dist/locale-ui.mjs` 保存每个界面文字节点的原文，实时翻译新增提示，并可准确切回中文。模型 ID、配方、价格、NFT 编号和存档继续使用原始数据。普通商店和 NFT 市场同时接受中英文名称及原有 ID 搜索；地图上的货物提示同样跟随语言。

## 蔬菜与伐木

- **蔬菜种植**：经营币商店提供乡村菜地、灌溉蔬菜园、高效蔬菜农场三档，价格 70／125／210 经营币。每批消耗 2 清水、产出 3 蔬菜；基础周期 14／12／11 秒，另计灌溉、遮阴及搬运影响。需要接通道路与货仓。6 蔬菜一车出售 60 经营币、18 星星。
- **伐木**：简易伐木场、改良伐木场、高效林业站价格 140／250／420 经营币，基础周期 16／14／13 秒，另计搬运。普通采伐范围 3 格。先在附近种植果树（20 经营币／棵）；每批采伐一棵成熟树，产出 3 木材。树立即变成树桩，90 个游戏秒后再生，幼树与树桩不可重复砍伐，两个伐木场不会重复使用同一棵树。须有可行走路线，景观装饰树不算原料。3 木材一车出售 75 经营币、25 星星。
- **NFT 对应型号**：青畦蔬菜园（18 TOM，10 秒基础周期）、林间伐木场（32 TOM，12 秒基础周期、4 格采伐范围）。已拥有的 NFT 按件免费部署；伐木 NFT 仍需要真实成熟树木。普通设施使用经营币购买。
- **完整货物流转**：蔬菜和木材均由村民搬运，到仓库后才增加可用库存；与面粉、面包、牛奶、蛋糕共享货仓容量。满仓不会继续扣水或砍新树。贸易面板增加两种订单，货车回站后结算；库存搜索、预警、自动出售、销售报表和 CSV 导出同步支持新货物。
- **存档与重建**：旧存档新货物从 0 开始，现有资产和日阶段奖励保留。暂停或关闭页面不加速树木生长。新一轮仍清空库存与批次，沿用布局时按价重购菜地、伐木场和果树；新买的树从成熟状态开始。

`test/produce-and-forestry.test.mjs` 验证实际种植、树木采伐与再生、竞争同一棵树、满仓停工、搬运入库、货车结算、自动出售、NFT 已付批次保留和存档迁移。


## 性能优化

- 地形与围栏按视角、道路、建筑占位、昼夜等条件缓存；静止画面直接复用底图。
- 静态建筑使用有限容量的精灵缓存。旋转、缩放、树木再生与作物进度变化会更新对应缓存，淘汰时释放画布背板。
- 去掉普通设施逐个绘图指令的 GPU 饱和度滤镜，保留普通设施木灰配色、NFT 青绿底座和金色标记。
- 村民状态每次游戏更新计算一次，逐帧只按已保存路线插值；路线长度缓存随新路线自动更新。路网改为相邻格索引，共享一次同步读取中的拓扑与容量，下一次读取重新建立，避免跨建造／拆除／切换账户使用旧状态。
- 界面数值不变时不重写 DOM，翻译观察器避免重复处理自身更新。地图拖动时的仓库标记用 transform 定位。
- 背景、市场、弹窗遮挡、地图滚出视口时减少或停止地图绘制；暂停保留画面，挑战仍按真实时间计时。
- 自动生产存档合并为最多每 3 秒写入；玩家购买、建造、领奖等动作及离开页面时立即保存。存档键继续使用 `meadow-farm-world-v6`。
- 设置 → 声音与画面 → 画面质量，可选“自动”“优先流畅”“优先清晰”。默认自动限制高分辨率画布的像素量，不改变地图坐标、产出速度或运输规则。

同一测试存档与同一地图视口的对比数据见 [性能验证记录](performance-report.md)。正常游戏无需开启诊断；开发检查可在本地地址添加 `?perf=1` 查看渲染统计。

## 小镇成长玩法（完整版）

主屏新增“小镇事务”和成长条，打开后按需使用村民委托、农场研究、生产调度、天气预报、经营成就。保留本地存档键 `meadow-farm-world-v6`，旧农场不重开、不拆除、不补算历史经验，学生及教师教学包不变。

- **村民委托**：9 种邻里混合订单模板，每次提供 3 个候选。基础订单使用小麦、面粉、面包；建好菜园、伐木场、牧场、蛋糕房后出现相应需求。一次接 1 单，限时 300 个游戏秒；暂停或关闭页面时不推进，区别于 TOM 挑战的真实倒计时。库存备齐后由村民到仓库自提，一次性扣除全部要求的货物、支付经营币、经验和 1 研究点。既不占货车，也不计入 TOM 挑战发货和货车销售报表。库存不足不扣货；放弃或超时不扣库存。每个游戏日（180 秒）更新候选，已接单保留；也可支付 25 经营币刷新，冷却 120 游戏秒。准备期自动出售为已接单保留对应数量；正在挑战时仍优先挑战交付，委托面板明确提醒另留库存。
- **十级农场成长**：等级经验门槛为 0／60／160／320／600／1000／1600／2400／3600／5200 XP。货物实际卸入仓库才记录产出并获得经验，水和电不提供经验；货车回站另给 8 XP，委托按订单给予经验。开工、搬运动画和满仓等待都不重复给经验。每升一级给 2 研究点，跨级和刷新不会重复发点。
- **三个研究方向，各三级**：精细生产每级基础周期缩短 6%，仓储规划每级已接通仓储容量增加 12%，高效物流每级搬运与货车时间缩短 10%。各方向第 1／2／3 级分别需要农场 Lv.2／3／4，消耗 1／2／3 研究点。生产和运输按整秒结算，最短周期、搬运和货车时间有限制；仓储仍须启用且道路连通。普通设施和 NFT 都能受益，NFT 型号差异保留。升级影响新批次和新发车，不重置已付批次、不重新扣料、不改变在途车辆的到站时刻。
- **可选天气**：默认关闭加成，可在预报面板主动开启。晴朗使太阳能基础周期缩短 20%；春雨使小麦、蔬菜、水井缩短 20%；微风使磨坊、风力机缩短 20%；温润使小麦、蔬菜、牧场缩短 10%。四种天气按游戏日循环，提供三日预报。只有加成，不追加灾害或额外任务门槛；太阳能夜间仍停，原料和搬运照常消耗。已付款批次保持进度。
- **生产调度**：集中查看全部生产设施的位置、普通／NFT 身份、配方、周期、当前状态和阻塞原因，可筛选暂停或等待的产线。普通设施和 NFT 均可暂停／恢复，已付款批次保留。可主动暂停下游工坊，为其他用途留出原料；恢复后从原进度继续。
- **八项经营成就**：面包 12、蔬菜 30、木材 18、货车往返 10 次、委托 3 单、研究累计 3 级、蛋糕 20、农场 Lv.5，分别提供经营币及研究点，主动领取，每项每账户只领一次。新一轮保留经验、研究点、研究等级、累计经营记录、成就领取记录和天气偏好，清空本轮未完成委托。TOM 奖励和每日五阶段规则沿用原机制。

实现：`dist/village.mjs` 管理规则，`dist/village-ui.mjs` 管理双语交互；只在游戏更新时刷新界面，倒计时单独更新，不增加地图逐帧的委托或成就计算。

验证：`node --test test/*.test.mjs`，覆盖入库经验、研究消耗与实际效果、在途批次保留、委托原子扣货、重复支付防护、过期／放弃／刷新、自动出售保留量、旧档迁移、跨轮保存，以及原五阶段可完成性。

玩法灵感来自官方说明中的 [Hay Day 访客需求](https://support.supercell.com/hay-day/en/articles/town-visitors-2.html)、[Hay Day 生产与专精](https://support.supercell.com/hay-day/en/articles/products.html) 和 [Town Star 多产品生产链与布局影响](https://news.gala.com/common-ground-world/the-town-star-rulebook/)。本版订单、研究数值和天气规则为本项目设计。

## 单屏操作布局

农场页改为适配视口高度的游戏工作区。地图在中央，快捷建造栏常驻地图下方，“给小镇添点新意”不再位于页面底部。左侧常驻发展路线、NFT 资产、村民委托、研究、生产调度、天气和成就入口；右侧库存／贸易／挑战／发展／资产按标签切换。“下一步，让小镇往哪里生长？”及其三条产业路线移入发展面板，一次点击即可查看。顶部保留开始、暂停、建造、库存、报表、设置、帮助和资金／经验概览。

新手教程在右侧独立查看，底部只保留当前上下文提示。长列表、订单说明等详细内容可在右侧面板内滚动，农场主页不需要整体向下滚动。小于 900px 宽度时，经营面板使用可收起的侧栏，切换按钮保留在地图和建造栏之间。资产市场保持其原有列表浏览方式。

`dist/farm-shell.mjs` 移动原有 DOM 节点，保留设施、商店、交易、任务和翻译绑定，不复制库存、资金或控件。`dist/farm-shell.css` 负责视口布局和窄屏适配。存档、生产规则、地图拖动旋转缩放及教学包保持原有机制。浏览器检查覆盖 1280×720、1024×700 和 390×844 的页面边界，以及双语、建造模式、面板切换和产业路线跳转。
